# 百日梦想家·封面轰炸机

一个面向真人口播视频的封面设计 Skill。

它不负责把画面堆满，而是专注于一件事：用真实人物、核心实物和一记醒目的标题，让观众第一眼看懂这期视频在讲什么。

## 核心特点

- 优先使用本人真实照片，不用陌生人替代
- 用户提供实物、Logo 或界面时，优先复用原素材
- 主体通常控制在 1～2 个，避免画面杂乱
- 标题短、狠、醒目，准确表达视频立场
- 默认保持真实摄影感，不自动动漫化
- 横版与竖版分别生成，绝不拼成一张图
- 适用于教程、观点、吐槽、生活和合集类口播封面

## 安装

```bash
npx skills add GoGoGo13579/dreamer-cover-bomber
```

## 使用

在支持 Skills 的环境中调用：

```text
@dreamer-cover-bomber
```

示例：

```text
使用 @dreamer-cover-bomber 为这期真人口播设计一套横竖版封面。
主题：AI 公司追求的东西，和数学界真正想要的东西正在严重错位。
```
