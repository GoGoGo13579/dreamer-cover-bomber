## ✨ 它是做什么的？

这是一个面向真人口播视频的封面设计 Skill。

它不负责把画面堆满，而是专注于一件事：

> 用真实人物、一个核心元素和一记醒目的标题，  
> 让观众第一眼就看懂这期视频在讲什么。

适用于教程、观点、吐槽、生活分享和合集栏目等内容。

## 🎯 核心原则

| 原则 | 具体表现 |
|---|---|
| **人必须像本人** | 优先使用本人真实照片，不用陌生人替代 |
| **实物必须真实** | 已提供产品、Logo 或界面时，优先复用原素材 |
| **主体必须够少** | 通常只保留“人物 + 一个核心元素” |
| **标题必须够狠** | 短、醒目、准确表达视频立场 |
| **画面必须干净** | 不堆装饰，不做廉价营销广告风 |
| **横竖必须分开** | 3:4 与 4:3 分别生成，绝不拼图 |
